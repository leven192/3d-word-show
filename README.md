# GLB 模型查看器

一个零依赖的 Three.js GLB 查看网页，加载当前目录下的 `model.glb` 并显示。
控制面板使用 Three.js 官方推荐的 **lil-gui** 库（深色极客风 UI）。

## 使用方法

1. 把从 C4D 导出的模型文件命名为 `model.glb`，放到本目录
   （C4D 导出：文件 → 导出 → glTF/GLB，格式选 **glb**）

2. **双击运行 `启动.bat`**（唯一入口，自动完成所有事）：
   - 清理旧实例 → 确保本地依赖（没有会自动下载一次）→ 重建最新发布包
   - 启动服务器（自动内嵌最新模型）+ 启动公网隧道（获取最新分享地址）
   - 打开网页 → 同步发布包到腾讯云 COS（永久链接，电脑关机也能打开）

> ⚠️ 不要直接双击 `index.html` 打开，浏览器安全限制会导致无法加载模型。
> 必须通过本地服务器访问（即 `启动.bat`）。

> 说明：首次运行会自动下载 three.js 到本地 `lib/`（需联网，一次性）；
> 若未下载成功，页面会自动退回到 CDN 加载（国内网络可能慢）。

## 每次启动自动更新分享链接（无需刷新网页）

`启动.bat` 每次点击都会：

1. **清理旧实例**（旧服务器 / 旧隧道，确保用最新文件重新启动）
2. 重建发布包 + 重启服务器（自动内嵌最新 `model.glb`）+ 启动隧道（获取**最新公网地址**）
3. 把最新地址写入 `share-config.js` 和 `current-url.txt`，并复制到剪贴板
4. 打开页面 → 同步到腾讯云 COS（永久链接保持最新）

**已打开的网页不用关**：页面每 5 秒自动从本地服务器读取最新公网地址，
发现变化后**自动更新分享链接和二维码**（右下角会弹出"分享地址已更新"提示）。

## 微信分享

**原理**：微信里打开的链接必须是公网 HTTPS 地址，所以需要用隧道工具把本地服务器"穿透"到公网。

**步骤（推荐 cpolar，国内访问最稳）：**

1. 注册并下载 **cpolar**：https://www.cpolar.com/ （免费版即可，安装 Windows 版）
2. 双击运行 **`启动.bat`**
3. **首次**运行，隧道窗口会提示输入 **cpolar Authtoken**（登录 https://dashboard.cpolar.com → Auth 页面复制），输入后自动保存并登录，以后无需再输入
4. 等 10~30 秒，隧道窗口会显示公网链接并**复制到剪贴板**，直接粘贴到微信发送即可
5. 网页右下角有「分享 / 二维码」按钮，可让手机**微信扫一扫**直接打开

**备选（全球可用，国内可能不稳定）：** 下载 cloudflared 单文件（无需注册）：
https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe
重命名为 `cloudflared.exe` 放到本目录，`启动.bat` 会自动优先使用它。

**注意：**

- **cpolar 隧道的本地端口必须指向 8000**（cpolar 默认是 80，需要在 cpolar 面板 `http://127.0.0.1:9200` 修改或新建指向 8000 的隧道），否则手机打不开
- 隧道窗口拿到链接后会自动自测一次，直接告诉你通不通、不通该查什么
- 隧道窗口保持开启时链接才有效，按回车即关闭；免费版隧道每次重启链接都会变化（页面会自动同步新地址）
- 微信内置浏览器若提示"无法访问/已停止访问"，点右上角菜单选「在浏览器中打开」
- `model.glb` 越大加载越慢，微信里建议控制在 **20MB 以内**（超大模型可先在 C4D 里减面）
- 手机微信需较新版本（内置浏览器内核较旧时会提示升级，页面已做兼容提示）

## iPhone / 微信打不开排查

先分清是哪一步打不开（按顺序测）：

1. **电脑浏览器**打开 cpolar 面板 `http://127.0.0.1:9200` 里显示的**最新**地址（别用旧地址，免费版每次重启都会变）
   - 电脑打不开 → 隧道问题：没在线 / 本地端口不是 8000 / 会话过期。重新双击 `启动.bat`
2. 电脑能开，**iPhone Safari** 打不开 → 手机网络到该域名的问题：换个 WiFi / 开 4G 试试
3. iPhone Safari 能开，**微信里**打不开 → 微信外链拦截：点微信右上角菜单「在浏览器中打开」，或复制链接到 Safari
4. 微信显示"已停止访问该网页" → 域名被微信拦截，一般只能复制链接用浏览器打开

**关于地址变化**：cpolar 免费版隧道重启后公网地址会变。`启动.bat` 每次运行都会把**最新地址**自动写进
`share-config.js` / `current-url.txt`，页面「分享/复制/二维码」会自动使用新地址——已打开的网页也会
每 5 秒自动同步，**无需刷新**，也不用再手动改任何配置。

**其他**：页面加载成功但模型不显示，或出现明确错误提示，多半是手机内核 WebGL 问题（页面已做降级和提示）。

## 电脑关机也能访问（部署到云托管）

**原理**：隧道（cpolar）依赖你的电脑开机运行服务器，关机就 404。要让链接 7×24 可访问，
必须把文件放到在线的托管服务上。你的页面是纯静态的（库在本地 `lib/`、模型内嵌），
任何静态托管都能直接跑。

**步骤（已并入 `启动.bat`，无需单独操作）**：

1. 双击 **`启动.bat`**，最后一步会自动同步到腾讯云 COS
   （首次运行需输入腾讯云 API 密钥：控制台 → 访问管理 CAM → API 密钥管理）
2. 同步完成后脚本打印网站地址，发微信即可 —— **电脑关机也能打开**

**更新模型**：导出新 `model.glb` → 双击 `启动.bat`（自动重建发布包 + 增量同步，秒级完成）。

## 操作

**鼠标：** 左键旋转 · 右键平移 · 滚轮缩放

**右上角 lil-gui 控制面板：**

| 分组 | 控件 | 说明 |
| --- | --- | --- |
| 视图 | 重置视角 | 相机自动对准模型 |
| 视图 | 自动旋转 | 开关环绕观察 |
| 视图 | 旋转速度 | 自动旋转速度 0~10 |
| 视图 | 视野 FOV | 相机视野 20~120 |
| 模型 | 线框 | 切换线框显示 |
| 模型 | 参考网格 | 显示/隐藏地面网格 |
| 模型 | 模型着色 | 开启后为模型整体上色（关闭恢复原色） |
| 模型 | 模型颜色 | 着色/白膜模式使用的颜色，可实时调整 |
| 模型 | 白膜模式 | 用纯色 PBR 材质替换全部材质（适合白膜导出预览，关闭恢复原材质） |
| 模型 | 白膜粗糙度 / 白膜金属度 | 白膜材质的粗糙度与金属度 |
| 渲染 | 色调映射 | ACESFilmic / Neutral / 关闭，颜色观感不对时可切换对比 |
| 渲染 | 曝光 | 色调映射曝光 0.2~3 |
| 渲染 | 背景色 | 场景背景颜色 |

**其他：** 把 .glb 文件直接拖进页面可替换模型（左上角显示当前模型名）

## 文件说明

- `index.html` — 查看器页面（优先加载本地 `lib/` 依赖与内嵌模型，缺失时自动回退；右下角含分享/二维码）
- `lib/` — 本地依赖目录（`启动.bat` 检测缺失时自动下载一次）
- `model-embedded.js` — 模型内嵌文件（服务器启动时自动从 `model.glb` 生成，页面内存解析模型、零网络请求，任何浏览器都不会卡在模型加载）
- `启动.bat` — **唯一入口**：清理旧实例 → 检查依赖 → 重建发布包 → 启动服务器 + 隧道 → 打开网页 → 同步到 COS
- `server.ps1` — 静态文件服务器（gzip 压缩 + lib 缓存 + 自动内嵌模型 + 端口重试 + 请求日志）
- `share.ps1` — 隧道辅助：获取最新公网地址，写入 `share-config.js` / `current-url.txt` 并复制到剪贴板（需安装 cpolar 或 cloudflared）
- `build-static.ps1` — 重建 `发布/` 静态发布包（页面 + 库 + 内嵌模型）
- `sync-cos.ps1` — 增量同步 `发布/` 到腾讯云 COS（永久链接，电脑关机也能访问；首次需输入 API 密钥）
- `download-deps.ps1` — 一次性下载 three.js / lil-gui 到 `lib/`（`启动.bat` 自动调用）
